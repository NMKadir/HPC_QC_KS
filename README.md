# HPC_QC_KS
We present a Fourier spectral solver for the one-dimensional Kuramoto--Sivashinsky equation (KSE), a canonical model of spatiotemporal chaos, integrated in time with the fourth-order exponential time-differencing Runge--Kutta scheme (ETDRK4). We have done two parts for this project, one is fully classical and other one is hybrid classical-quantum implementation. Classically, we implement and benchmark four backends: a serial CPU baseline, a shared-memory OpenMP version, a distributed-memory MPI version using FFTW-MPI, and a GPU version using cuFFT. All backends are validated against one another; because the KSE is chaotic, exact long-time agreement across different floating-point summation orders is not expected. We additionally implement a small-scale hybrid module in which the spectral transform step is replaced by a Quantum Fourier Transform (QFT) circuit, simulated with Qiskit, demonstrating feasibility of a quantum-classical hybrid spectral pipeline at reduced problem size. We report speedup and scaling results for all classical backends, discuss hardware-dependent limitations (notably double-precision throughput on consumer GPUs), and outline extensions toward Koopman or Carleman-operator-based quantum simulation of the full and nonlinear chaotic dynamics.
